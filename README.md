# Image Quick Copy · 图片快捷复制

Hover over an image in Chrome and press **⌘C / Ctrl+C** to copy the image itself. No floating copy button.

在 Chrome 网页中，把鼠标移到图片上，按平常的复制快捷键，就能把图片本身放进剪贴板。

## 安装

1. 从 [Releases](https://github.com/heshengshi/image-quick-copy/releases/latest) 下载 `image-quick-copy-v0.2.0.zip` 并解压。保留解压后的文件夹，安装后不要移动或删除它。
2. 在 Chrome 地址栏输入 `chrome://extensions/`。
3. 开启右上角的「开发者模式」，点击「加载未打包的扩展程序」，选择解压后包含 `manifest.json` 的文件夹。
4. 刷新要使用的网页。如果安装过旧版，请先停用旧版，避免重复运行。

扩展及本地安装方式免费。当前版本通过 GitHub 分发；没有 Chrome Web Store 上架链接。

## 使用

1. 鼠标移到目标图片上。
2. Mac 按 **⌘C**；Windows / Linux 按 **Ctrl+C**。
3. 出现「✓ 图片已复制」后，到支持图片粘贴的聊天框、文档或图片编辑器按 **⌘V / Ctrl+V**。

选中了网页文字，或焦点还在输入框、编辑器里时，快捷键继续复制文字。要复制图片，先单击网页空白处取消文字选择、移出输入框，再把鼠标移到图片上。

悬停时会提前准备图片，以减少按键后的等待。连续换图时，新的复制请求会替代尚未写入的旧请求；只有剪贴板写入成功才显示成功提示。若显示失败，请勿把剪贴板里的旧内容当成刚复制的图片。

## 支持范围与限制

- 复制为静态 PNG，使用网页当前实际加载的图片分辨率，不自动获取所谓「原图」。
- 支持常规 `<img>`、部分 CSS 背景图和浏览器允许读取的 `<canvas>`；动图不保留动画。
- 一般用于 HTTPS 网页。非安全 HTTP 页、Chrome 内部页面、扩展商店、受限的嵌入框架和跨域画布可能无法使用。
- 带有特殊遮罩、多个重叠图片或封闭 Shadow DOM 的页面可能识别失败。
- 图片读取、PNG 转换各有 15 MiB 限制，像素总数上限为 3000 万。
- **不支持在 Finder 文件夹里直接粘贴成图片文件。**
- 本版没有自动更新；更新时需下载新版本，再在扩展管理页重新加载。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `clipboardWrite` | 在用户按复制快捷键后写入图片，不读取剪贴板。 |
| `http://*/*`、`https://*/*` 的网页和图片访问权限 | 在不同网站定位鼠标指向的图片，并在需要时取得跨域图片用于 PNG 转换。 |

没有分析服务、广告、远程脚本、账号系统或图片上传服务器。图片转换在本机浏览器内完成；图片预取或复制仍可能向图片原站发起请求。详见 [隐私说明](PRIVACY.md)。

## 验证记录

v0.2.0 已在 macOS Chrome 中完成以下人工测试，并回读系统剪贴板：

- Pinterest 连续复制三张不同图片，尺寸及 SHA-256 均发生对应变化。
- Wikipedia 和 Python 官网图片复制。
- 鼠标指向图片时，输入框文字、网页文字选区仍按正常方式复制。

这份记录不代表已覆盖所有网站，也不代表 Windows / Linux 已完成实机测试。悬停准备完成后的写入速度不等于首次加载图片的耗时。

## 开发与检查

无运行依赖，无需构建。使用 Node.js 22 或更新版本：

```sh
npm test
```

检查包括快捷键与编辑区保护、图片 URL 过滤、缓存隔离、失败重试及连续复制的并发顺序。检查命令不会安装第三方包。

发现兼容性问题，可以通过 [Issues](https://github.com/heshengshi/image-quick-copy/issues) 提供公开页面链接、Chrome 版本、扩展版本、操作步骤和错误提示。请勿提交账号凭据、私人图片或含敏感信息的截图。
